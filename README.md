# 🎬 Netflix Data Analysis | Microsoft Excel

## 📌 Project Overview

This project explores the Netflix Movies and TV Shows dataset using **Microsoft Excel**, with the goal of transforming raw data into meaningful insights through data quality assessment, exploratory data analysis (EDA), and data visualization.

The project focuses on understanding Netflix's content library, identifying distribution patterns, and exploring trends over time.

## 📊 Dataset Overview

- **Total Records:** 8,790
- **Total Columns:** 10
- **Content Types:** Movies and TV Shows
- **Release Years:** 1925 – 2021

### Dataset Features
- `show_id`
- `type`
- `title`
- `director`
- `country`
- `date_added`
- `release_year`
- `rating`
- `duration`
- `listed_in`

## 🧹 Data Quality Assessment

The dataset was examined to assess its quality and consistency.

Key activities included:
- Checking missing and blank values.
- Identifying unknown values represented as `Not Given`.
- Verifying unique Show IDs.
- Checking data types and date formats.
- Investigating potential inconsistencies between release years and Netflix addition dates.

**Data Quality Findings:**
- No blank cells were found in the examined columns.
- 2,588 records have unknown director information.
- 287 records have unknown country information.
- All 8,790 Show IDs are unique.
- 14 records were flagged for potential date inconsistencies and require further investigation.

## 🔍 Exploratory Data Analysis (EDA)

The analysis explored several aspects of Netflix's content library:

1. **Content Type Distribution:** Comparing Movies and TV Shows.
2. **Release Year Analysis:** Exploring content distribution across release years.
3. **Country Analysis:** Identifying countries contributing to Netflix's content library.
4. **Rating Analysis:** Examining content distribution by age rating.
5. **Content Addition Trends:** Analyzing how Netflix's catalog additions changed over time.
6. **Country and Content Type Comparison:** Comparing Movies and TV Shows across countries.

## 📈 Key Insights

- Movies represent approximately **69.69%** of the dataset.
- TV Shows account for approximately **30.31%**.
- The dataset contains **6,126 Movies** and **2,664 TV Shows**.
- **2018** recorded the highest number of titles by release year, with **1,146 titles**.
- The period from 2016 to 2020 represents a particularly strong concentration of titles.
